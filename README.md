## التشغيل محليًا
```bash
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

## الاستضافة على Vercel
```bash
npm i -g vercel
vercel --prod
```
أو اربط هذا المستودع من لوحة Vercel وسيُنشر كموقع ثابت مباشرة.
